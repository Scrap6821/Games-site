How to add more games:
1. Put each game’s HTML file inside the games folder.
2. In index.html, copy a game card and change its title, description, and button’s game ID.
3. Add that ID and filename to the gameFiles list in the script below.
4. Publish the folder on GitHub Pages for free. All games must be HTML/JavaScript or other browser-compatible files.
